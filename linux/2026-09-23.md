**오늘 배운 내용**
- Linear RAID, RAID0, RAID1, RAID5 장치의 고장 난 디스크를 새로운 디스크로 교체

**개념**
- 없음 
  
**명령어**
- mdadm --add 추가할 장치이름 : 새로운 디스크 추가
  
**헷갈렸던 것 / 에러**
- 없음
  
**정리**
- Linear RAID, RAID0, RAID1, RAID5의 원상복구
  - 실습: 고장 난 장치를 새로운 디스크로 교체
    - a. VMware에서 새로운 SCSI 장치를 추가
    - b. 새로 장착한 디스크를 파티션
    - c1. 결함허용이 안되는 RAID(Linear, 0)일 경우
    - 고장난 RAID장치 작동 중지(mdadm --stop)
    - RAID 재구성(예: mdadm --create /dev/md9 --level=linear --raid-devices=2 /dev/sdb1 /dev/sdc1)
    - c2. 결함허용이 되는 RAID(1,5)일 경우
    - 새로운 디스크 추가(mdadm --add 추가할 장치)
    - d. mdadm --detail --scan 복사 내용 gedit /etc/mdadm.conf의 기존 내용 지우고 붙여넣기
    - e. gedit /etc/fstab에서 #주석 제거
    - f. reboot

## 2026-10-07 리눅스 8주차 Day1

**오늘 배운 내용**
- 네임 서버의 개념과 작동

**개념**
- 네임 서버(DNS서버): URL을 IP주소로 변환시켜주는 역할
  - 예): www.hanbit.co.kr -> 218.38.58.195 
 
**명령어**
- nslookup: 네임 서버의 IP주소 확인
  
**헷갈렸던 것 / 에러**
- 없음
 
**정리**
- IP 주소를 얻는 내부 흐름
  - a. URL 입력 (예: www.hanbit.co.kr)
  - b. /etc/host.conf 조회 --> order hosts,bind로 hosts 파일을 먼저, 그다음 DNS(bind) 순서로 확인
  - c1. /etc/hosts에서 해당 URL의 IP가 있는지 확인 --> 있으면 IP 주소 획득, 끝
  - c2. hosts에 없으면 /etc/resolv.conf(네임서버 설정) 확인
    - 네임서버 설정이 없으면 --> 호스트 이름을 알 수 없음 (실패)
    - 네임서버 설정이 있으면 --> 네임서버에 질의
      - 응답 있음 --> IP 주소 획득, 끝
      - 응답 없음 --> 호스트 이름을 알 수 없음 (실패)

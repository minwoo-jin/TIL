## 2026-10-27 리눅스 10주차 Day5

**오늘 배운 내용**
- 워드프레스를 활용한 웹사이트 구축

**개념**
- 워드프레스: 웹사이트를 통합적으로 구성하도록 도와주는 오픈소스 도구 
 
**명령어**
- DB사용자,이름, 비번 설정 SQL문: GRANT ALL PRIVILEGES ON 데이터베이스 이름.* TO 사용자@localhost IDENTIFIED BY '비밀번호'; 
  
**헷갈렸던 것 / 에러**
- 없음
 
**정리**
- 실습: 워드프레스를 설치하고 운영
  - Server
    - mariaDB에 접속하여 데이터베이스 사용자 wpUser와 wpDB이름의 데이터베이스를 만듦(CREATE, GRANT)
    - 워드프레스 설치, 압축해제
    - 해제한 폴더를 apache폴더로 이동(mv wordpress /var/www/html/)
    - cd /var/www/html/
    - 권한 및 소유자 변경(chmod 707 wordpress, chown -R apache.apache wordpress)
    - 설정 파일을 복사(cp)
    - wp-config.php, httpd.conf 파일 편집
    - 서비스 재시작(systemctl restart httpd)
  - WinClient
    - 웹 서버에 접속해 워드프레스 초기설정 진행
    - 관리자로 로그인하여 웹사이트 만들기

## 2026-09-28 리눅스 6주차 Day3

**오늘 배운 내용**
- LVM의 구성과 구현

**개념**
- LVM: 여러 개의 디스크(물리 볼륨)를 묶어서 1개의 볼륨 그룹으로 만든 후 다시 필요한 용량의 파티션(논리 그룹)으로 나눠서 사용하는 방식
  - 예: 2TB 용량의 하드디스크 2개를 합친 후에 다시 1TB와 3TB로 나눠 사용 가능
    - 물리 볼륨: /dev/sda1 등의 파티션
    - 볼륨 그룹: 물리 볼륨을 합쳐서 1개의 물리 그룹으로 만든 것
    - 논리 볼륨: 볼륨 그룹을 1개 이상으로 나눈 것

**명령어**
- pvcreate 장치이름: 물리 볼륨 생성
- vgcreate: 볼륨 그룹 생성
  - 예: vgcreate myVG /dev/sdb1 /dev/sdc1: 2개의 물리볼륨 하나로 묶기(볼륨 그룹(myVG) 생성)
- lvcreate : 볼륨 그룹의 파티션 생성
  - 예: lvcreate --size 1g --name myLG1 myVG(1G크기 생성)
  - 예: lvcreate --size 3g --name myLG2 myVG(3G크기 생성)
  - 예: lvcreate --extents 100%FREE --name myLG3 myVG(나머지 용량 모두 할당하여 생성)

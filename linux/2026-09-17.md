## 2026-09-17 리눅스 5주차 Day2

**오늘 배운 내용**
- RAID의 정의와 개념

- RAID 레벨(Linear RAID, FAID 0~5까지 총 7가지로 분류)
  - Linear RAID: 2개 이상의 하드디스크, 1번째부터 차례대로 저장
  - RAID 0: 2개 이상의 하드디스크, 모든 디스크에 동시 저장(Stripping방식)
    - 속도: 뛰어남, 신뢰도(결함허용): X, 공간효율성: 좋음
  - RAID 1: 동일한 데이터를 각 디스크에 모두 저장(Mirroring방식)
    - 속도: 변화없음, 신뢰도(결함허용): O, 공간효율성: 나쁨
  - RAID 5: 최소 3개 이상의 하드디스크 
    - RAID1의 안전성 + RAID0의 공간효율성
    - 오류 발생시 패리티(Parity)를 이용해 데이터 복구(패리티 데이터가 디스크 개수-1의 공간 사용)
  - RAID 6: 최소 4개 이상의 하드디스크
    - 2개의 디스크가 동시에 고장나도 데이터에 이상이 없는 방식
  - RAID1+0: = RAID1 + RAID0
    - 신뢰성(안정성)과 성능(속도)가 동시에 뛰어남 

**개념**
- RAID: 여러 개의 디스크를 하나의 디스크처럼 사용하는 방식
  - 특징: 비용 절감, 신뢰성 증가, 성능 향상
  - 종류: 하드웨어 RAID, 소프트웨어 RAID

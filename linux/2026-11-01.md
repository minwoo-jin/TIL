**정리**
- 실습1: Windows의 폴더를 공유하고 그 폴더를 리눅스에서 접근해서 사용
  - a. WinClient(Samba서버)
    - a1. Windows의 폴더를 공유
      - C드라이브에서 smbShare라는 새폴더 생성
      - 속성 -> 공유폴더로 만들기
      - 공유할 사람: Everyone, 권한: 읽기쓰기
      - 적당한 파일 추가
    - a2. 파워 셸에서 명령 입력
      - 리눅스의 사용자를 추가, 비밀번호 지정(net user root 1234 /add)
      - IP주소확인(ipconfig)
  - b. Server(Samba클라이언트)
    - samba-client 패키지 설치
    - 공유된 폴더와 프린터 확인(smbclient -L WinClient의IP주소)
    - 마운트할 디렉터리 생성(mkdir /sambaMount)
    - 마운트(mount -t cifs //WinClient의IP주소/smbShare /sambaMount)
    - 마운트 확인(ls -l /smbShare)

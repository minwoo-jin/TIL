## 2026-10-04 리눅스 7주차 Day4

**오늘 배운 내용**
- 텔넷 서버 구축 

**개념**
- 텔넷: 오랫동안 사용되어 온 원격 접속 방법
 
**명령어**
- 없음 
  
**헷갈렸던 것 / 에러**
- WinClient 설치에 문제가 있었음. 
  - 이유: WinClient에 Windows를 설치해야하는데 Windows10 enterprise 평가판 서비스를 종료하여 Windows10 환경을 쓰고있는 나는 설치가 불가하였음. 
  - 해결: WinClient는 실습없이 책과 강의내용만 학습하였고 실습은 Server로만 실시하였음 
 
**정리**
- 텔넷 서버 구축
  - a. 텔넷 서버 설치(dnf -y install telnet-server)
  - b. 텔넷 서비스 시작(systemctl start telnet.socket)
  - c. 텔넷 전용 사용자 생성(adduser 사용자이름, passwd 비밀번호)
  - d. 방화벽 포트열기(firewall-config)
  - e. 텔넷 서비스 상시 가동(systemctl enable telnet.socket)
  - f. 클라이언트에서 접속(telnet 서버IP 입력)

**오늘 배운 내용**

- Firefox 웹브라우저를 최신 버전으로 업데이트

**개념**
- 노틸러스 : 그놈 데스크톱 환경의 기본 파일 관리자
- firefox : Rocky Linux에서 기본 제공하는 웹 브라우저
- 에볼루션 : 이메일 클라이언트

**명령어**
- 없음
  
**헷갈렸던 것 / 에러**
- 다운로드한 파일의 압축을 풀고 새로운 버전의 Firefox 웹브라우저를 설치하는 과정
  - cd ~/다운로드/ 
  - tar xfj fireTab 	--> 압축풀기
  - su 			--> root사용자 권한 얻기
  - mv firefox /usr/local/
  - chown -R root.root usr/local/firefox --> firefox 관련 파일 모두 root사용자 소유로 변경
  - cd /usr/local/bin/
  - ln -s /usr/local/firefox/firefox .   --> 현재 디렉터리에 firefox 웹브라우저 링크를 새로 생성
 
**정리**
- X윈도 응용 프로그램 중 노틸러스와 firefox에 대해 알아보고 관련해 기본적인 실습을 함.

**정리**
- 실습1: naver.com과 daum.net 도메인을 관리하는 네임 서버 구현

- a. Server(메일서버): 호스트 이름을 mail.naver.com으로 설정
  - 센드메일 설치(dnf -y install sendmail)
  - gedit에디터로 /etc/hostname, /etc/hosts, /etc/mail/local-host-names, /etc/sysconfig/network 수정
  - reboot(설정 적용)
- b. Server(B): 호스트 이름을 mail.daum.com으로 설정
  - 센드메일 설치
  - nano에디터로 ""위와같음
  - reboot(설정 적용)
- c. Server(네임서버): naver.com 도메인과 daum.net 도메인의 네임 서버를 설정
  - 네임서버 설치(dnf -y install bind bind-chroot)
  - gedit /etc/named.conf 파일 수정
  - cd /var/named
    - 파일 생성(touch naver.com.db daum.net.db)
    - 파일 수정(gedit /var/named/naver.com.db, /daum.net.db)
  - 이상 유뮤 확인(named-checkconf)
  - 네임서버 재시작, 상시가동, 상태확인(systemctl)
  - 방화벽 실행 정지(systmectl stop/disable firewalld)
  - 네임서버 설정확인(nslookup -> 두개의 도메인 입력)
- d1. Server(메일서버): 메일서버의 네임서버를 192.168.111.100로 설정
  - 네트워크 파일 수정(gedit /Nettab/systab/enstab)
  - gedit /etc/resolv.conf 파일 수정
- d2. Server(B): 네임서버를 192.168.111.100로 설정
 - 위와 동일
 - 네임서버 설정확인(nslookup -> 두개의 도메인 입력)
- d3. Client 네임서버를 192.168.111.100로 설정
  - /etc/resolv.conf 파일 수정(su -c)
  - 네임서버 설정확인(nslookup -> 두개의 도메인 입력)
- d4. WinClient 네임서버를 192.168.111.100로 설정
  - 파워쉘에서 네임서버 변경(netsh)
  - 네임서버 설정확인(nslookup -> 두개의 도메인 입력)

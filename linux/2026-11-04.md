## 2026-11-04 리눅스 12주차 Day1

**오늘 배운 내용**
- DHCP 서버 구현

**개념**
- DHCP서버: 자신의 네트워크 안에 있는 클라이언트 컴퓨터가 부팅될 때 자동으로 IP주소, DNS서버주소 등을 자동으로 할당해주는 역할
 
**명령어**
- 없음 

**헷갈렸던 것 / 에러**
- 없음
 
**정리**
- 실습: DHCP서버 구현(Server: DHCP서버 / Server(B),Client: DHCP 클라이언트)
  - a. CIient: DHCP서버에서 IP 자동 할당받고있는지 확인
    - IPv4설정확인(nm-connection-editor)
    - IP주소 자동할당 확인(ifconfig ens160, /etc/resolv.conf)
  - b. 호스트OS(VmWare pro)
    - setting -> DHCP 서비스 중지
  - c. Client: DHCP클라이언트로 구축
    - DHCP클라이언트 설치(su -c 'dnf -y install dhcp-client')
    - reboot
    - ifconfig ens160(DHCP서버가 없으므로 IP주소 할당X)
  - d. Server(B): DHCP클라이언트로 구축
    - 네트워크 확인(ping -c) -> 고정 IP주소를 가지고 있으므로 DHCP작동과 상관없이 네트워크 연결O
    - 네트워크 설정파일 편집(nano -c /etc/NetTab/sysTab/ensTab) -> DHCP클라이언트로 설정
    - 네트워크 장치 중지/시작(nmcli connection down/up ens160)
    - reboot
    - ifconfig ens160 -> (IP주소 할당X)
  - e. Server: DHCP서버로 구축
    - 설치(dnf -y install dhcp-server)
    - 설정파일 생성,편집(gedit /etc/dhcp/.dhcpd.conf)
    - IP주소 대여 정보기록 파일 확인(ls -l or touch /var/lib/dhcpd/dhcpd.leases)
    - 서비스 시작, 상시가동(dhcpd)
  - f. Client: 새로운 IP 정보 할당받기
    - 네트워크 다시시작(su -c 'systmectl restart NerTab')
    - ifconfig ens160 -> 설정한 숫자범위 사이의 IP주소 할당O
    - 웹브라우저로 인터넷 접속확인
  - g. Server(B): 새로운 IP 정보 할당받기
    - 네트워크 다시시작(systemctl restart NerTab)
    - 인터넷 확인(ping -c)
  - h. Server: 네트워크 정보 대여 기록 확인가능
    - /var/lib/dhcpd/dhcpd.leases

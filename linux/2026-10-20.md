**정리**
- 실습1: Server 가상머신을 DBMS 전용 서버로 운영(mariaDB 데이터베이스 서버 설치)
  - mariaDB 다운로드 및 압축 해제
  - mariaDB 서비스 시작 및 상시가동(systemctl)
  - 방화벽 설정(firewall-config에서 mysql 가동)
  - 접속 확인(터미널에 mysql)
- 실습2: mariaDB의 기본적인 보안설정(WinClient)
  - a. Server
    - DB터미널 관리자 root 비번 설정(mysqladmin) 
  - b. WinClinet
    - windows용 mariaDB 클라이언트 설치
    - mariaDB서버로 접속(파워셸)
      - CD C:\Program Files\MariaDB 10.9\bin\
      - 파일확인(DIR mysql.exe)
      - mariaDB 클라이언트 실행(mysql)
  - c. Server: WinClient에서 접속할 사용자 생성
    - mariaDB 접속(mysql -u root -p)
    - 데이터베이스 사용자 확인(USE, SELECT)
    - 새로운 사용자 생성(GRANT)
  - d. WinClient
    - Server에서 만든 winuser사용자로 접속(mysql -h 192.168.111.100 -u winuser -p)

## 2026-10-10 리눅스 8주차 Day3

**오늘 배운 내용**
- Server에 thisislinux.com의 마스터 네임 서버를 설치하고 운영
  - Server를 네임 서버와 웹 서버 용도로 구축
  - Server(B)를 FTP 서버로 구축 

**개념**
- 마스터 네임 서버: 도메인에 속해있는 컴퓨터들의 이름을 관리하고, 외부에 해당 컴퓨터의 IP주소를 알려주는 역할
  - = 내가 직접 관리하는 도메인의 "정답 주소록"을 가진 네임(DNS) 서버
  - 캐싱 기능에 더해, 자기 도메인(예: thisislinux.com)의 주소록을 직접 갖고 있음. 그 도메인에 대해서는 남에게 안 물어보고 바로 답함.
- 포워트 존 파일: "도메인 이름 → IP 주소" 를 적어두는 DNS 장부

**정리**
- 실습: Server에 thisislinux.com의 마스터 네임 서버를 설치하고 운영
  - a. Server에서 웹서버 설정
    - 웹서버 설치(dnf install httpd)
    - 웹서비스 작동시작(systemctl status/start httpd)
    - 방화벽 설정(http,https)
    - 초기 웹 페이지 작성(gedit /var/www/html/index.html)
  - b. Server(B)에서 FTP서버 설정
    - FTP 서버 설치(dnf install vsftpd)
    - 방화벽 설정, 적용(firewall-cmd --permanent --add-sevice=ftp, firewall-cmd --reload)
    - 환영 메세지 파일 생성(welcome.msg파일 생성, /etc/vsftpd/vsftpd.conf파일 편집)
    - FTP 서버 시작(systemctl restart vsftpd)
  - c. Server에서 thisislinux.com 도메인 설정
    - /etc/named.conf 파일 편집
    - 문법 확인(named-checkconf)
    - 포워드 좀 파일 생성, 편집(touch/gedit thisislinux.con.db)
    - 문법 확인
    - 네임 서비스 재시작 및 가동확인(systemctl restart/status named)
  - d. Client(여기선  테스트용 PC)에서 마스터 네임서버 작동 확인
    - Server --> 네임 서버의 IP주소가 Server 가상머신의 IP주소로 되어있는지 확인(cat /etc/resolv.conf)
    - 웹 브라우저에서 www.thisislinux.com접속
    - Server(B) --> FTP클라이언트 패키지 설치(sudo dnf install ftp)
    - FTP서버에 접속(ftp ftp thisislinux.con.db)

**정리**
- A. 변수와 연산 
  - 변수 사용법 
    - 변수에 문자열을 저장할 때는 변수명 앞에 $를 붙여 값을 출력 
    - $가 포함된 문자열을 그대로 출력하려면 ''로 묶거나 앞에 \를 붙임 
    - 변수를 ""로 묶으면 변수의 내용이 출력 
  - 사용자 입력 받기 
    - read 명령어를 사용하여 사용자로부터 값을 입력받아 변수에 저장할 수 있음 
    - 예) read myvar 명령 후 입력한 값은 myvar 변수에 저장됨 
  - 숫자 계산 
    - 변수에 저장된 값은 기본적으로 문자열로 취급되지만, expr 명령어를 사용하면 숫자로 인식하여 계산
    - expr 명령어 사용 시 ''가 아닌 역따옴표(``)를 사용해야 함.
    - 곱하기나 괄호 연산을 할 때는 앞에 \를 붙여야 함
    - 예) expr $num1 + 200은 num1 변수의 값을 숫자로 인식하여 200을 더함

- B. 파라미터 변수와 조건문 
  - 파라미터 변수 
    - 스크립트 실행 시 전달되는 값들은 파라미터 변수로 사용된다. 
    - $0은 실행 파일의 이름, $1은 첫 번째 파라미터, $2는 두 번째 파라미터, $*는 모든 파라미터를 한 번에 나타냄
  - if 조건문 
    - if 문은 특정 조건이 참일 때 코드를 실행하는 데 사용됨 
    - 기본 구조는 if [ 조건 ] then 실행문 fi 이며, 조건문과 then 사이에 공백이 있어야 함 
    - if else 문은 조건이 참일 때와 거짓일 때 각각 다른 코드를 실행할 수 있음 
    - 비교 연산자:
      - 문자열 비교, 수식 비교(p.459참고)
    - 파일 관련 조건(p.460참고)

- C. case 문과 논리 연산 
  - case 문 
    - case 문은 여러 개의 조건 중 하나를 만족할 때 해당 코드를 실행하는 다중 분기문
    - 구조는 case 변수 in 패턴1) 실행문1 ;; 패턴2) 실행문2 ;; *) 그 외 실행문 ;; esac 임 
    - 각 패턴 끝에는 ;;를 붙여야 함
    - *는 위에서 정의되지 않은 모든 경우를 처리함 
    - 예) 사용자 입력($1)이 "start", "stop", "restart"일 때 각각 다른 동작을 수행하도록 할 수 있음 
  - 논리 연산자 
    - and 연산 (-a 또는 &&): 두 조건이 모두 참일 때 참임
    - or 연산 (-o 또는 ||): 두 조건 중 하나만 참이어도 참임 
    - 예) 파일이 존재하고(-e) 파일 크기가 0이 아닐 때(-s) 파일 내용을 출력하는 조건에 사용됨

- D. 반복문 활용 
  - for 반복문 
    - for 반복문은 지정된 목록의 항목들을 하나씩 변수에 할당하며 반복 실행함
    - 구조: for 변수 in 목록; do 실행문; done  
  - while 반복문 
    - while 반복문은 조건식이 참인 동안 계속 반복 실행됨
    - 구조: while [ 조건 ]; do 실행문; done 
    - 무한 반복을 하려면 while true 또는 while 1을 사용함 
  - until 반복문 
    - until 반복문은 조건식이 거짓인 동안 계속 반복 실행됨 
    - while 문과 반대되는 개념으로, 조건이 참이 되면 반복을 멈춤 
    - while 문으로 작성된 코드를 until 문으로 쉽게 바꿀 수 있음 

- E. 1.5. 제어문, 함수, 고급 기능 
  - 제어문 
    - break: 반복문을 즉시 종료하고 빠져나옴 
    - continue: 반복문의 현재 단계를 건너뛰고 다음 단계로 넘어감
    - exit: 프로그램을 완전히 종료시킴
    - return: 함수 내에서 사용되며, 함수를 호출한 곳으로 돌아감
  - 사용자 정의 함수 
    - 직접 함수를 정의하여 코드를 재사용할 수 있음 
    - 정의: 함수이름() { 함수 내용 } 
    - 호출: 함수 이름을 입력하면 됨 
    - 함수 내에서 파라미터를 사용하려면 $1, $2 등을 사용함 
    - eval 명령어는 문자열을 명령문으로 인식하여 실행함 
  - 변수 범위와 출력 형식 
    - export: 변수를 외부 변수로 선언하여 다른 프로그램에서도 사용할 수 있게 함 
    - 지역 변수는 해당 스크립트 내에서만 유효함 
    - printf 명령어를 사용하여 출력 형식을 지정할 수 있음 
      - %f: 실수를 지정된 자릿수와 소수점 이하 자릿수로 출력함 
      - %s: 문자열을 출력함 
  - 명령어 결과 활용 
    - 명령어의 실행 결과를 변수에 저장하거나 파라미터로 $를 사용함 
    - 예) date 명령어의 결과를 today 변수에 저장하고, 그 결과를 활용하여 요일을 출력할 수 있음
  - shift 명령어 
    - 파라미터 변수들을 왼쪽으로 한 칸씩 이동시킴 
    - 많은 수의 파라미터를 순차적으로 처리할 때 유용함 
    - while 문과 함께 사용하여 파라미터가 비어있지 않은 동안 계속 shift를 실행함

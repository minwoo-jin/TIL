**정리**
- 실습: Server 가상머신을 NFS서버로 구축하고 Client 가상머신을 NFS 클라이언트로 설정
  - a. Server: NSF 서버를 설정
    - 패키지 설치 확인 및 설치(rpm -qa nfs-utils, dnf -y install nfs-utils)
    - 설정파일 열고 공유할 디렉터리 추가(gedit /etc/exports)
      - /share *(rw,sync)  -> *는 서버에 접근할 컴퓨터의 IP주소를 전체로 설정
    - 서버 공유 디렉터리 생성(mkdir /share)
    - 접근 권한 설정(chmod 707 /share)
    - cp 적당한 파일 /share
    - nfs-server 시스템 재시작 및 상시가동
    - 서비스 가동 중 확인(exportfs -v)
    - 방화벽 끄기
  - b. Client: NFS 서버에 접속하여 공유한 디렉터리 사용
    - 패키지 설치 확인 및 설치
    - NFS서버에 공유된 디렉터리 확인(showmount -e NFS서버IP주소)
    - 홈 디렉으로 이동(cd)
    - 클라이언트 마운트 디렉터리 생성(mkdir myShare)
    - su -c ;mount -t nfs NFS서버IP주소:/share myShare'
    - 공유확인(ls -l myShare)
    - 부팅시 NFS서버의 디렉터리에 자동 마운트되도록 설정(gedit /etc/fstab)
      - NFS서버IP:/share  /home/rocky/myshare  nfs  defaults  0  0
    - 재부팅 후 자동 마운트 확인(ls -l /home/rocky/myShare)

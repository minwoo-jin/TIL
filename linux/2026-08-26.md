## 2026-08-26 리눅스 2주차 Day1

**오늘 배운 내용**
- Server 가상머신에 CD/DVD 마운트
- Client 가상머신 USB 메모리 마운트(USB없는 관계로 실습X)
- 텍스트 모드(Server(B))에서 CD/DVD와 USB 메모리 마운트(USB는 실습X)
 
- 개념: mount
  
**헷갈렸던 것 / 에러**
- {mount 정보 확인 -> CD/DVD or USB 삽입 -> 마운트된 CD/DVD or USB 사용} 이 일련의 과정들 속의 명령들이 헷갈렸음.
- x윈도에서는 CD/DVD가 자동으로 연결되지만 텍스트모드에선 수동으로 연결해야함. 

** 정리**
- 총 3개의 가상머신을 사용하여 CD/DVD와 USB를 마운트하여 사용하는 법을 배움.

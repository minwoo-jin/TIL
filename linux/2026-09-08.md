## 2026-09-08 리눅스 3주차 Day6

**오늘 배운 내용**
- 파이프, 필터, 리디렉션
- 프로세스, 서비스
- 서비스와 소켓

**개념**
- 파이프 : 2개의 프로그램을 연결하는 통로(|문자를 사용)
  - 예) ls -l /etc | more : 페이지 나눠서 출력

- 필터 : 필요한 것만 걸러주는 명령어(grep, tail, wc, sort 등)
  - 주로 파이프와 같이 사용
  - 예) ps -ef | grep bash : bash 글자가 들어간 프로세스만 출력

- 리디렉션 : 표준 입출력의 방향을 바꿔줌
  - 예) ls -l > list.txt : ls -l 명령의 결과를 list.txt 파일에 저장

- 프로세스 : 하드디스크에 저장된 프로그램이 메모리에 로딩되어 활성화된 것
  - 프크라운드 프로세스 : 화면에 나타서 사용자와 상호작용
  - 백그라운드 프로세스 : 바이러스 백신, 서비스 등 화면에 나타나지않음
  - 프로세스 번호 : 프로세스에 할당된 고유번호
  - 작업 번호 : 백그라운드 프로세스의 순차번호

- 서비스(데몬) : 시스템과 독자적으로 구동되어 제공하는 서비스
  - 예) 웹 서버(httpd), DB서버(mysqld), FTP서버(vsftpd)
  - systemctl start/stop/restart 서비스이름 : 실행 및 종료
  - 서비스의 실행 스크립트 파일 확인--> /usr/lib/systemd/system/ 

- 소켓 : 서비스와 반대되는 개념으로, 필요할 때만 작동하는 서버 프로세스
  - (외부에서 특정 서비스를 요청할 경우 systemd가 소켓을 구동, 요청이 끝나면 종료)

 
**명령어**
- ps : 현재 프로세스의 상태를 확인
  - ps -ef | grep 프로세스이름 : 프로세스 번호 및 상태 확인

- kill : 프로세스 강제 종료
  - kill -9 프로세스번호 : 무한 루프도는 프로세스 등을 강제 종료

- pstree : 부모와 자식 프로세스의 관계를 트리 형태로 출력

- 에디터이름 & : 백그라운드로 프로세스 실행
  - 예) gedit &, vi 파일이름 &

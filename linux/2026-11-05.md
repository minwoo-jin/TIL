  - 한번 전송한 데이터를 캐시에 저장한 후, 같은 데이터를 또 요청할 경우 캐시에 저장된 것을 보냄
 
**명령어**
- 없음
  
**헷갈렸던 것 / 에러**
- 없음
 
**정리**
- 실습: 프록시 서버 구현(Rocky linux에서 제공하는 squid 프록시 서버 사용)
  - Server: 프록시 서버 구축
    - dnf -y install squid
    - gedit /erc/squid/squid.conf 수정
    - 3128번 포트 허용(firewall-cmd)
  - Client: 프록시 사용으로 변경
    - 웹브라우저 설정 -> 수동 프록시 설정
  - Server: 프록시 서비스 시작
    - 시스템 재시작, 상시가동(squid)
  - Client: 작동테스트
    - 웹브라우저 -> 아무 사이트 접속 -> 정상접속(프록시 서버 작동O, 웹 데이터 캐시저장)
  - WinClient: 프록시 설정 및 작동테스트
    - 설정 -> 프록시 -> 수동프록시 설정 -> 웹사이트 접속 -> 정상접속(프록시 서버 작동O, 웹 데이터 캐시저장)

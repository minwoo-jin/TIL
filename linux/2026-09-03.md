## 2026-09-03 리눅스 3주차 Day1

**오늘 배운 내용**
- 의존성 문제가 있는 패키지를 dnf 명령을 실행하여 설치
- dnf 명령을 실행할 때 필요한 파일을 네트워크가 아닌 DVD에 설치
- 패키지 그룹 설치 (텍스트 모드로 이동)(x윈도에선 영문패키지가 한글로 표시됨)

**개념**
- DNF : rpm 패키지를 편리하게 설치할 수 있게 도와주는 도구 (의존성 문제 해결)
 
**명령어**
- dnf -y install 패키지이름 (설치), dnf -y remove 패키지이름 (삭제)
- dnf groupinstall "패키지그룹이름" (패키지 그룹설치)
- dnf clean all (기존 저장소 목록 삭제) 
  
**헷갈렸던 것 / 에러**
- dnf 명령을 실행할 때 필요한 파일을 네트워크가 아닌 DVD에 설치하는 과정(p237)
 
**정리**
- 오늘은 편리하게 패키지를 설치하는 DNF에 대해 배웠고, 관련 명령어들을 사용하여 rpm 명령으로 설치할 수없는
패키지들을 설치하는 등 여러가지 실습을 해봄.

## 2026-10-16 리눅스 9주차 Day2

**오늘 배운 내용**
- 지난 실습에 이어 naver.com 메일서버와 daum.net 메일서버 구현

**개념**
- dovecot: 이메일 수신 서버 소프트웨어
  - 사용자에게 메일 박스의 내용을 보내는 서비스
 
**명령어**
- 없음
  
**헷갈렸던 것 / 에러**
- 파일 수정 중 mail_location의 주석제거를 제대로 하지않아 메일박스에 제대로 메일이 수신되지않는 오류가 있었음. 
 
**정리**
- 실습2: naver.com 메일서버와 daum.net 메일서버 구현

- a. Server(메일서버): naver.com 메일서버 구축
  - 메일서버 구현 패키지(dnf -y install sendmail-cf dovecot)
  - sendmail서버의 설정 파일 수정(gedit /etc/mail/sendmail.cf)
  - 외부 네트워크 or 호스트가 메일을 보낼 수 있게 허가(gedit /etc/mail/access수정)
  - 설정 적용(makemap hash /etc/mail/access < /etc/mail/access)
  - dovecot 설정파일 수정
    - gedit /etc/dovecot/dovecot.conf 
    - gedit /etc/dovecot/conf.d/10-ssl.conf 
    - gedit /etc/dovecot/conf.d/10-mail.conf
  - 메일계정 사용자,암호 생성(useradd lee, passwd lee)
  - sendmail 및 dovecot 서비스 시작, 상시가동(systemctl)
- b. Client: naver.com 메일서버 테스트
  - 에볼루션 설정
  - 새로만들기 -> 자기자신에게 보내기
  - 보내기/받기 -> 받은 편지함 확인
- c. Server(B): daum.net 메일서버 구축
  - { docecot 설정파일 수정까지 naver.com 메일서버 구축과 동일 }
  - 메일계정 사용자,암호 생성(useradd kim, passwd kim)
  - sendmail 및 dovecot 서비스 시작, 상시가동(systemctl)
- d. WinClient: kim@daum.net 으로 접속 후 lee@naver.com에게 메일 보내기
  - 메일 클라이언트 설치: 썬더버드 다운로드
  - 메일 계정 설정
  - 쓰기 -> lee@naver.com에게 메일 보내기
  - Client에서 보내기/받기를 누르고 받은 편지함 확인 후 답장
  - WinClient에서 받기를 눌러 회신한 메일 확인

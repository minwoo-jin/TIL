## 2026-09-07 리눅스 3주차 Day5

**오늘 배운 내용**
- SELinux의 정의와 관련 명령어

**개념**
- SELinux : 시스템에서 보안에 영향을 미치는 서비스, 권한 등을 제어
 
**명령어**
- sestatus or getenforce : SELinux 활성화 여부확인
- grubby --update-kernel ALL --args selinux=0 : 비활성화
- grubby --update-kernel ALL --remove-args selinux : 활성화
  
**헷갈렸던 것 / 에러**
- 없음
 
**정리**
- 네트워크 보안하기 위한 SELinux에 대해 알아보았음.
- +) system-config-selinux 명령의 [현재 강제 모드]의 작동 방식
: '강제'(시스템 보안에 영향을 미치는 기능 감지 시 그 기능 작동X), 
  '허용'(시스템 보안에 영향을 미치는 기능 감지 시 허용 
  '비활성화'(SELinux를 사용하지 않음)

**개념**
- XRDP 서버: 원격지에서 X윈도 환경(그래픽 환경) 자체를 사용할 수 있음. 
 
**명령어**
- 없음 
  
**헷갈렸던 것 / 에러**
- 없음
 
**정리**
- XRDP 서버 구축 과정
  - EPEL 저장소에서 의 추가 패키지 설정 허용(dnf -y install epel-release)
  - XRDP 서버 설치(dnf -y install xrdp)
  - 서비스 시작, 상시 가동 설정(systemctl start xrdp, systemctl enable xrdp)
  - 방화벽 설정(firewall-config에서 포트번호 3389번 허용)
  - WinClient의 원격 데스크톱 연결기능으로 xrdp서버에 접속 

- 3가지 원격 접속 서버 비교
  - SSH: 기본적으로 사용
  - XRDP: 설정만 해놓고 가동하지 않음. X윈도 접속이 필요한 경우만 사용
  - 텔넷: 보안이 철저한 회사의 네트워크에서만 사용 권장
